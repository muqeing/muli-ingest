# 0.1.0 发布状态

## 已实现

- 冻结扫描范围；浏览页面和刷新来源不会开始复制。
- 保留目录结构、未知文件和空目录，目标发布不覆盖。
- 来源 Hash 随复制流计算，整批复制完成后集中回读目标并比较 BLAKE3。
- 可选择文件数量与大小的快速核验，回执明确记录核验方式。
- 多来源独立队列，默认并行 2 个来源，可设置 1–4 个。
- 文件级失败继续、中断恢复、有限重试和已核验副本复用。
- Markdown/JSON 清单、版本报告和最终完成回执。
- 14 天默认留存、按批延期、永久保留、保护锁、转存确认及清理预览。
- 本机回环模式，以及带固定口令、HttpOnly 会话、同源检查和登录限速的局域网模式。
- 非 root、只读根文件系统、能力收缩、来源只读挂载和健康检查的 Docker 配置。
- Linux/FNOS 挂载卷自动发现及刷新。

## 尚未完成

- 自动定时清理和回收站到期永久删除。
- FNOS 原生应用包、用户角色、HTTPS 证书和反向代理的自动配置。
- 所有 NAS 型号、USB 芯片组、文件系统、SMB 并发和异常拔插兼容性验证。
- 断电、磁盘写满、长时间离线和超大批次的完整压力矩阵。
- 进程异常退出后对外部复制子进程的自动接管。
- 清理过程中断恢复及“回执落盘但数据库提交未完成”的自动协调。

## 使用判断

0.1.0 适合在操作者监督下进行素材中转和核验。完成状态代表中转副本满足所选核验方式，不代表素材已经形成异地备份，也不代表可以自动格式化来源卡。每一种 NAS、读卡器和相机组合都应先完成小批量真实验收。
